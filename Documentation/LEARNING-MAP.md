The reusable guides live in [skills](../skills/README.md). This map connects each lesson to the actual implementation so an agent can inspect, adapt, and verify it. The original designs were developed for Daybeat, then extracted into this independent project. Historical product claims are context; no Daybeat application or health data is needed.

## Reproduce a tuning session

Start from the [tuning workflow](../skills/element-studio/references/tuning-workflow.md). Change one category at a time, hold a repeatable camera/light baseline, save the parameter values and source revision, and compare clay/front/side/reverse/detail/thumbnail output. Preserve a candidate separately before promoting it into the catalogue.

The complete current native fixtures are included. Historical editions preserve compatibility and are not regenerated by the current builders. The recovered environment and surface generators let contributors rebuild those inputs without the original private checkout. See [asset provenance](ASSET-PROVENANCE.md) and [authoring commands](../Authoring/README.md).

## Limits to carry forward

The hourglass is not a physical sand simulation. The native glass shader is not volumetric refraction. The browser's color pipeline is not proof of native color parity. Some original helper choices assume a single dominant outline. Historical measurements in REVIEW are dated observations, not guarantees. Skills teach these limits as well as the successful refinements.
